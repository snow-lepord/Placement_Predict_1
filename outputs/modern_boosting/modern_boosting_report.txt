What each library adds over sklearn's GradientBoostingClassifier:
  XGBoost:  regularized objective (L1/L2 on leaf weights), second-order
            gradient approximation, level-wise tree growth.
  LightGBM: leaf-wise tree growth and histogram-binned splits - built
            for speed on large datasets.
  CatBoost: native categorical handling via ordered target encoding,
            symmetric (oblivious) trees for fast inference.
